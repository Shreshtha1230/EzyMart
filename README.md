# EZYMART PRO 2K26 — Next-Gen E-Commerce Web Application

A complete, responsive, client-side E-Commerce web application built with **HTML5, CSS3, and Vanilla JavaScript (ES6+)** using `localStorage` for real-time state persistence across all pages.

## Key Features
- **Modern Glassmorphism UI + 3D Depth**: Floating frosted navbar, 3D product showcase cards, subtle glowing borders, smooth micro-animations, and **Dark / Light Theme Toggle**.
- **16-Product Dynamic Catalog (`product.html`)**: Live search, category filter pills, max-price slider, minimum rating filter, in-stock toggle, sorting, and URL query routing (`product.html?category=Gaming`).
- **Global Instant Search (`Ctrl + K`) & Quick View Modal**: Search from any page and pick product variants/sizes without leaving the screen.
- **Smart Shopping Cart (`cart.html`)**: Free-delivery progress bar, quantity controls, live GST (18%) calculation, and working promo codes:
  - `EZY20` — 20% Off
  - `FIRST500` — ₹500 Off (min ₹1,500)
  - `WELCOME10` — 10% Off
- **EzyPay Simple Payment Gateway (`checkout.html`)**:
  - **UPI / QR Code** with scannable SVG QR & quick UPI app presets
  - **Credit / Debit Card** with real-time **3D Virtual Card Preview**
  - **Net Banking** (SBI, HDFC, ICICI, Axis, Kotak, PNB)
  - **Cash on Delivery (COD)**
  - Explicit JavaScript form validation, simulated gateway authorization modal, and **Printable GST Invoice**.
- **My Orders & Live Delivery Tracker (`orders.html`)**: 4-step order progress tracker with interactive stage simulation.
- **Account System (`login.html`)**: Login/Sign-Up with explicit JS validation + 1-click Demo Login for presentations.

## How to Run
Simply extract the ZIP folder and double-click `index.html` in any modern browser (Chrome, Edge, Brave, Firefox). No server or installation required!
